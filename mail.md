Betreff: Presenter Tools: kostenlos zum Ausprobieren

Hallo,

ich habe mir für meine Präsentationen ein Windows-Tool gebaut, das Sie gern ausprobieren und nutzen können: Presenter Tools.

Es vereint drei Dinge, die ich beim Präsentieren täglich brauche:

- Mit der Pen Bar zeichnen Sie direkt auf den Bildschirm, mit Farben, Stiftstärken und verschiedenen Modi. Optimize ersetzt Ihre letzte Skizze durch sauberen Text oder klare Formen. Dafür hinterlegen Sie einen eigenen API Key unter Settings > AI.
- Mit Print Screen oder Capture nehmen Sie einen Bildschirmbereich auf. Die Screenshots landen in einer Library, in der Sie sie beschriften, zuschneiden und exportieren.
- Der AirPlay Receiver zeigt den Bildschirm von Apple-Geräten aus Ihrem lokalen Netzwerk auf dem PC an.

Presenter Tools läuft auf Windows 10 und 11 (x64), startet auf Wunsch mit Windows und wartet dann im Tray. Es ist Open Source unter MIT-Lizenz, Sie dürfen es also kostenlos nutzen, auch im Unternehmen.

Den Installer laden Sie hier herunter:
https://github.com/alexander-kastil/presenter-tools/releases/latest/download/PresenterTools.msi

Meldet Windows „Der Computer wurde durch Windows geschützt“, klicken Sie auf „Weitere Informationen“ und dann auf „Trotzdem ausführen“. Der Installer ist neu und hat bei SmartScreen noch keine Reputation.

Quellcode und Anleitungen finden Sie auf GitHub:
https://github.com/alexander-kastil/presenter-tools
